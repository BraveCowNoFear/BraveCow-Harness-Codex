# 发给朋友的提示词

把下面这段直接发给你朋友，让他交给 Codex：

```text
请帮我安装这个 Codex harness：
https://github.com/BraveCowNoFear/BraveCow-Harness-Codex

请先阅读 README.zh-CN.md，然后在仓库目录运行：
powershell -ExecutionPolicy Bypass -File .\install.ps1

安装完成后，用 agent-harness-introspect skill 检查本机 Codex harness，并告诉我：
1. 安装了哪些东西
2. 哪些 memory/skill/agent profile 已经生效
3. 有没有缺失或需要我手动处理的地方
```
