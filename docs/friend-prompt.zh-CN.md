# 发给朋友的安装提示词

把下面整段和仓库链接发给 Windows 或 macOS 上的 Codex / ZCode：

```text
请下载并安装 BraveCow Harness：
https://github.com/BraveCowNoFear/BraveCow-Harness-Codex

请先读取 README.zh-CN.md，再识别我使用的是 Windows 还是 macOS、Codex 还是 ZCode，并运行对应安装器。默认同时配置 Codex 和 ZCode，但不要覆盖我的已有记忆、AGENTS.md 自定义内容、账号或密钥。

安装完成后，请让安装器自动开启一个全新的“BraveCow 新手指南”任务；不要把教程塞在当前安装任务里。新任务应通过 $bravecow-onboarding 一课一课地教我，并等待我回答。
```

如果操作系统阻止 ZCode 自动按新任务快捷键，手动新建任务并输入：

```text
$bravecow-onboarding
```

ZCode 也可以运行 `/bravecow-onboarding`。
