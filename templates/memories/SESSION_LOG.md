# Session Log

Append short chronological notes here when a task produces reusable context that has not yet been promoted.

Recommended entry shape:

```text
## YYYY-MM-DD HH:MM - Short task label
- Outcome: what changed or was decided.
- Reuse: the preference, workaround, or follow-up worth retaining.
```

Do not store secrets or copy large transcripts into this file.
