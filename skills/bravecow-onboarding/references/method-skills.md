# Harness、Skill、插件与人物方法

## 四个概念

- **Skill**：可复用的工作流程、领域知识和边界说明。
- **插件**：给助手增加外部系统或工具能力；通常带来新的权限和供应链风险。
- **规则/记忆**：约束长期行为并保留稳定上下文，不是每次临时提示词。
- **Harness**：把 Skills、插件、规则、记忆、来源锁和检查机制组合成可维护工作层。

需要解释关系时显示 `assets/ui/shared/11-harness-map.png`；需要用户点击时改用当前平台对应的真实红圈图。

## 人物方法 Skill 的判断标准

人物方法 Skill 应蒸馏可执行流程，而不是模仿口头禅或冒充本人。评估时看：

1. 来源能否定位到原典、公开演讲、书籍或可核查材料。
2. 是否把事实、方法转译和当前推断分开。
3. 同一输入能否产生可观察的方法差异。
4. 是否给出行动、指标、反证条件或失效边界。
5. 是否明确不冒充、不伪造原话、不替用户作高风险最终决定。
6. 触发是否清晰，是否会在普通问题上误用。

安装量小不等于课程价值低；它只提示需要更认真检查来源、许可证、版本锁和执行面。只有口吻、第一人称身份和不可验证传记推断的 Skill 才不适合作为默认教学工具。

## 课程用法

- 先教 Skill 本身的结构，再选择一个与用户领域有关的方法镜头。
- 显式调用，不让人物镜头自动覆盖普通问答。
- 用同一输入做一次普通回答/方法回答对照，只比较流程差异，不比较“谁更权威”。
- 项目路线把方法镜头用于真实的小决策；原理路线使用无现实后果的中性案例。
- 若本机没有合适 Skill，只讲选择标准，不临时下载安装来凑演示。

## 高风险边界

升学、就业、医疗、法律、财务等强时效或高影响领域，必须按年份、地区和用户约束查询当前官方来源，明确不确定性，并把最终决定交还用户。人物方法只能帮助组织问题，不能替代专业判断或实时事实。

## ZCode Windows 演示

`$bravecow-windows-computer-use` 用来教学“插件增加行动能力”：先说明来源、锁定版本、能力、权限、验证和回退，再按 `references/zcode-computer-use-plugin.md` 只做无副作用验证。不要把人物方法 Skill 与桌面控制插件混为一类。
